❓ Perguntas frequentes

O jogo não abre / fecha sozinho

Confira os logs na aba Modloaders. 90% das vezes é: Java errado (1.17+ exige Java 17+), RAM acima do disponível, ou loader incompatível com a versão. Teste primeiro em Vanilla.

Offline entra em quais servidores?

Apenas servidores com online-mode=false (cracked/offline) e singleplayer. Servidores originais (Hypixel etc.) exigem conta Microsoft.

Minha skin não aparece

Instale o mod OfflineSkins pela aba Skins e jogue com Fabric/Forge/NeoForge/Quilt. Coloque seu PNG 64×64 — ele vira skins/skin.png.

Forge x NeoForge?

Forge: até 1.20.1, ecossistema gigante. NeoForge: 1.20.5+ (inclui 1.21), é o futuro. Fabric/Quilt: leves, melhor performance (Sodium+Iris).

Quanto de RAM?

Vanilla: 2–4 GB. Com mods/shaders: 4–8 GB. Nunca passe de 50–60% da RAM total.
